# 運用資料の管理

公開リポジトリには、公開可能な運用方針と検証結果の要約だけを保存する。

- 公開前の手順: [運用手順](../document/運用手順.md)
- 検証結果と残件: [公開前運用確認](../document/公開前運用確認_2026-10-20.md)
- Stripeの検証: [追加テスト](../document/Stripe追加テスト_2026-10-20.md)

バックアップの実装、ワークフロー、鍵管理用のローカルスクリプト、詳細な実施記録は、専用の非公開リポジトリで管理する。アプリ側の公開リポジトリからバックアップ処理を実行しない。

`operations/private/` はローカルの非公開作業用でありGit管理から除外する。接続情報、秘密値、復号鍵、DBデータは、非公開リポジトリにもコミットしない。実値を必要とする設定は承認済みのSecret等で管理する。

公開リポジトリへのコミット・pushと、本番設定の変更、通知の有効化、販売開始は別の操作として扱う。

旧Rails一式は `private/legacy-rails-20261025/backend/` にローカル保管する。同じディレクトリの `tracked-backend-da0366a.tar.gz` は削除前コミットの追跡対象268ファイルのアーカイブであり、内容照合済み。既存の旧DBボリューム・暗号化バックアップ・以前の保管アーカイブはそのまま保持する。保存先をGit管理へ戻さず、秘密値を含むローカル専用ファイルを公開しない。詳細は [旧Rails保管記録](../document/旧Rails保管_2026-10-25.md) を参照する。
