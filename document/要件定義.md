# 要件定義

## 参考情報
* 高等学校（情報）教員資格認定試験 科目Ⅰの過去問分析記事を参考にする
    * https://qiita.com/misato729/items/c9e35ab0141ab87932dc
* 科目Ⅰは全20問の4択問題で、6割以上が合格ライン
* 出題傾向は以下の大分類で整理する
    * 問1〜問15: 教職教養問題
    * 問16〜問20: 情報科特有問題
* 過去問が少なく傾向が変わる可能性があるため、問題分類や出題範囲はコード上の固定値として後から追加・変更できる設計にする
    * 分野の追加・変更頻度は低い想定のため、管理画面ではなく `utils` フォルダ内の配列で管理する

# サービス方針

* ユーザーがサイトを開いて、すぐに1問ずつ取り組める問題演習を中心機能とする
* 問題演習はログイン不要とする
* 未ログインユーザーの回答状態は画面内だけで保持し、サーバーには保存しない
* ログインユーザーに限り、回答履歴とお気に入りを保存する
* 問題は試験ナンバーごとに20問を配置し、複数の試験セットを用意できる構成とする
    * 試験セットは問題を整理する単位とし、受験セッションや試験結果は管理しない

# 機能要件

## ログイン機能
* 会員登録ができる
    * ユーザー名、メールアドレス、パスワードを登録する
    * メールアドレスは一意とする
    * パスワードは8文字以上とする
* ログインができる
* ログアウトができる
* アカウント削除（物理削除のみ）ができる
    * アカウント削除時、回答履歴・お気に入りも削除する

## 問題演習
* ログインの有無にかかわらず、公開中の問題を1問ずつ解くことができる
* 問題文と4つの選択肢を表示し、ユーザーが1つを選んで回答できる
* 問題文と選択肢では、令和7年度科目Ⅰの出題形式を基準として、以下の表示形式を扱えるようにする
    * 通常の文章
    * 枠付きの引用文
    * 表
    * 改行と字下げを保持したプログラム表記
    * 複数のプログラムを比較する表示
* 表はスマートフォンで横スクロールできるようにする
* 複数のプログラムは、表示幅が確保できる場合は横並び、スマートフォンでは縦並びで表示する
* 回答後に以下を表示する
    * 正解または不正解
    * 正答
    * 解答解説
    * 参考にした出題範囲・根拠資料
* 解答確認後、「次の問題」から別の問題へ進むことができる
* 同じ試験ナンバーの問題は、問1から問20までの順序を持つ
* 未ログインユーザーの回答内容および正解・不正解は保存しない
* ログインユーザーが回答した場合は、回答履歴を保存する
* 問題の正答は回答前に表示しない
* 問題・選択肢・解答解説は生成AIで作成する
* 問題には以下の情報を持たせる
    * 問題文
        * 問題文は、通常文、引用文、表、プログラムなどの表示ブロックを表示順に保持する
    * 試験ナンバー
    * 問番号（1〜20）
    * 4つの選択肢
        * 選択肢は通常文に加え、表形式の内容を保持できる
    * 正答
    * 解答解説
    * 大分類（教職教養、情報科特有）
    * 小分類
        * 教職教養：教育史、教育法規、学習指導要領、生徒指導提要、教育心理、令和の日本型学校教育
        * 情報科特有：学習指導要領(情報)、アルゴリズム、データサイエンス
    * 参考にした出題範囲・根拠資料
    * 公開状態（下書き、公開、非公開）
## 回答履歴
* ログインユーザー限定の機能とする
* 問題に回答したとき、以下の情報を保存する
    * 回答した問題
    * 選択した選択肢
    * 正解または不正解
    * 回答日時
* 自分の回答履歴を新しい順に確認できる
* 回答履歴から、過去に間違えた問題とその解説を確認できる
* 演習回単位の集計は行わず、回答を1問単位で管理する

## お気に入り
* ログインユーザー限定の機能とする
* 問題表示中に、分野表示の左側にある星アイコンからお気に入り登録・解除ができる
* 未登録時は輪郭だけの星、登録時は黄色で塗りつぶした星を表示する
* お気に入り登録した問題を一覧で確認できる
* 未ログインユーザーが星アイコンを押した場合は、会員登録後に利用できる旨と、会員登録・ログインへの導線をモーダルで表示する

## 試験概要ページ閲覧
* 高等学校（情報）教員資格認定試験についての情報を掲載する。
* 1ページ内に試験概要と過去問ベースの出題範囲の解説を掲載する
* 科目Ⅰの概要として、問題数、選択肢形式、合格ライン、出題範囲を掲載する
* 出題範囲は以下の観点で掲載する
    * 教職教養
    * 情報科特有の問題
    * 学習指導要領・学習指導要領解説
    * 教育法規
    * 生徒指導・教育心理
    * アルゴリズム・データサイエンス
* 出題傾向は年度によって変わる可能性があることを明記する

## 管理機能
* 管理者は問題を作成・編集・削除できる
* 管理者は問題の公開状態を変更できる
* 管理者は各問題の試験ナンバーと問番号を設定できる

# 非機能要件
* パスワードはハッシュ化して保存
* 認証方式は Rails API と Nuxt の構成に合わせて決定する
    * Cookie ベース認証またはトークンベース認証を検討する
    * 本番環境では HTTPS を前提とする
* フロントエンドとバックエンドのドメインが分かれるため、CORS 設定を行う
* 個人開発なのでレスポンスが遅すぎなければOK
    * Vercel(FE),Fly.io(BE),Neon(DB)の無料枠で十分な想定
    * 無料枠のスリープにより初回アクセスが遅くなる可能性は許容する
* 経費削減のためドメイン取得は行わない（Vercel上で動かす想定）
* スマートフォンでも主要機能を利用できるレスポンシブデザインとする
* データベースは定期的にバックアップできる構成にする
* 生成AIで作成した問題には誤りが含まれる可能性があるため、ユーザーにその旨を明示する
