## 主な発見

### 1. 選択肢内の語句の頻度から正答を復元できる32問

列ごとに最多の語を残すと、正答行だけが一意に残る問題がある。全候補同数の列は、何も絞らないものとして判定した。正答の語が多いという印象ではなく、実際に残る行を確認した。

| 問番号 | 該当する模試番号 |
| --- | --- |
| 問8 | 10・11・14・16 |
| 問10 | 8 |
| 問11 | 7 |
| 問15 | 7・10 |
| 問16 | 6・9・11〜15 |
| 問17 | 3・4・7・11〜15 |
| 問18 | 5〜8・11〜15 |

計32問。表型選択肢の機械抽出で31問を検出し、通常の文章選択肢に五つの対応を並べる7-15を通読で追加した。例えば11-16は前三列の正答語が各3回、別語が各1回であり、その三列だけでウとなる。出典や概念を難しくせず、誤答の組合せを均衡させる改稿が適している。

一列が3対1でも、他の列の判断が残るものはこの32問へ入れていない。「穴埋めの候補を少し絞れる」と「正答行を復元できる」を区別した。

### 2. 再掲・文法・未提示参照

- 5-6は見出し「学習評価の充実」が空欄の手掛かりになり、不自然な受身表現の誤答もある。13-9には全体計画等が再掲される。1-16は空欄の答え「問題の発見・解決」が後半に残る。
- 正答語が残っていても、それを入れることが文脈上必然とは限らない。2-16のネットワーク／システムや8-17の効率は、別の候補でも意味が成立するため、単純な文字一致から「原典不要で確定」とは判定しなかった。2-16は改善候補、8-17は標準知識による解答として維持。
- 9-4の「次項各号」は対象となる学校教育法第81条第2項各号が未提示。法令には他にも参照先補足の候補があり、各詳細へ記載した。学習指導要領等の既存の補足を、参照があるという理由だけで再度不良にはしていない。
- 2-17は指導計画の見出しから（1）を表示せず（2）（3）へ進む。「抜粋」として連続性の表示を整える候補であり、条文の内容や正答の誤りとは別である。

### 3. 極端な誤答と、縦に続く同じ消去法

問11・12・14・15、及び問18の初期に、支援しない、一律に扱う、他内容と関連付けない等の誤答が集中する。知識のない人でも、穏当な正答だけを残しやすい。特に問12の模試1〜10は、状態像と支援方法の具体的な対応へ判定点を移す改稿を優先したい。

問12の後半には、「一つの能力があれば別の能力も同じ水準である」という取り違えが続く。一方、それを退けること自体が障害理解の重要な内容である問題も多い。32・35・47・49は再点検し、語調だけによる自動消去とは断定せず、誤答型の配分を変える改善候補にとどめた。

### 4. 人物の難しさと、実際に必要な判断数

4-13はエルキンドの想像上の観衆・個人的寓話を正答必須とする。以前の「標準的な主要人物を優先する」合意に反し、優先改稿とした。難化のために人物をマイナーにする必要はない。

逆に、設問に並んだ用語・統計量・コードの総数を、そのまま正答に必須の負荷とは数えなかった。

- 12-19はAの平均比較回数が4であることだけで、③を含む三肢を消してアとなる。二コードを全て追う高負荷問題ではなく、比較対象Bを使わず解ける配分の改善候補。
- 11-20は中央値1.5と最頻値1だけでイとなり、四分位数を計算しなくてよい。四分位数を測るなら、その判断も必要になる誤答配分へ変える候補。
- 20-20の分散・標準偏差は小さいデータと整数の計算に収まるため維持。10-18もトランザクションという一つの標準概念で正答へ到達できるため、ACID全特性を同時に要求する難問とは扱わない。
