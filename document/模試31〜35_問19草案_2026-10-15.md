## 模試31・問19

配列dataについて，先頭と末尾を除き，直前と直後の要素の両方より値が大きい要素の個数を数えたい。同じ値であれば「大きい」には含めない。次のプログラムの空欄 ① に入れる条件として正しいものを，下のア～エの中から一つ選んで記号で答えなさい。

```text
01 data = [2, 5, 5, 3, 6, 1, 4]
02 count = 0
03 iを1から要素数(data)-2まで1ずつ増やしながら繰り返す:
04     if 【①】:
05         count = count + 1
06 表示する(count)
```

ア　`data[i] > data[i-1] or data[i] > data[i+1]`

イ　`data[i] > data[i-1] and data[i] > data[i+1]`

ウ　`data[i] >= data[i-1] and data[i] >= data[i+1]`

エ　`data[i] < data[i-1] and data[i] < data[i+1]`

正答：イ

解説：

- ア：左右の少なくとも一方より大きければ数えてしまう。提示データでは添字1・2・4の3個となる。添字1の値5は右隣と等しく，添字2の値5は左隣と等しいため，求める条件を満たさない。
- イ：両隣との厳密な大小比較を`and`で結ぶ。提示データでは添字4の値6だけが両隣の3と1より大きく，表示は1となる。
- ウ：等しい値も含むため，添字1・2の値5まで数えてしまい，3個となる。「両方より大きい」と「両方以上」を区別する。
- エ：両隣より小さい要素を数える。提示データでは添字3の値3と添字5の値1の2個となり，求める大小関係が逆である。

## 模試32・問19

配列dataの各要素を一つ前の位置へ移し，元の先頭の値を末尾へ移したい。例えば，`[3, 8, 1]`を`[8, 1, 3]`へ変える処理である。次のプログラムの空欄 ① に入れる処理として正しいものを，下のア～エの中から一つ選んで記号で答えなさい。tempは反復前の先頭の値を保存する変数である。

```text
01 data = [4, 9, 2, 7, 5]
02 n = 要素数(data)
03 temp = data[0]
04 iを0からn-2まで1ずつ増やしながら繰り返す:
05     data[i] = data[i+1]
06 【①】
07 表示する(data)
```

ア　`data[0] = temp`

イ　`data[n-1] = data[0]`

ウ　`data[n-1] = temp`

エ　`data[0] = data[n-1]`

正答：ウ

解説：

- ア：保存した値を先頭へ戻すため，結果は`[4, 2, 7, 5, 5]`となる。元の先頭の値を入れる位置は末尾である。
- イ：反復後のdata[0]は元の2番目の値9に変わっている。その値を末尾へ入れるため，結果は`[9, 2, 7, 5, 9]`となり，元の先頭の値4が失われる。
- ウ：反復終了時は`[9, 2, 7, 5, 5]`であり，tempには元の先頭の値4が残る。末尾data[n-1]へtempを代入すると，目的の`[9, 2, 7, 5, 4]`になる。
- エ：反復後に末尾の値5を先頭へ入れてしまい，結果は`[5, 2, 7, 5, 5]`となる。退避した値の復元先と，代入元の両方が異なる。

## 模試33・問19

次のプログラムを実行したときに表示される値として正しいものを，下のア～エの中から一つ選んで記号で答えなさい。`break`は，実行された時点で最も内側の反復を終了し，反復の後の処理へ進む命令である。配列dataの要素は先頭から順に取り出す。

```text
01 data = [3, 5, -2, 7, -1, 4]
02 total = 0
03 xをdataの先頭から順に取り出しながら繰り返す:
04     if x < 0:
05         break
06     total = total + x
07 表示する(total)
```

ア　6

イ　16

ウ　8

エ　0

正答：ウ

解説：

- ア：3と5を加えた後，-2を加算すると6になる。しかし，-2を取り出したときは05行で反復を終了するため，06行の加算は実行されない。
- イ：全要素を足すと16になる。しかし，このプログラムは最初の負の値-2で反復を終了するため，その値と，その後の7・-1・4は加算されない。
- ウ：3を加えてtotalが3，次の5を加えて8となる。次の-2で反復を終了するので，表示は8である。
- エ：totalは0から始まるが，最初の3と次の5では負の値という条件を満たさず，加算が実行される。初期値0のままではない。

## 模試34・問19

次のプログラムを実行したときに表示される値として正しいものを，下のア～エの中から一つ選んで記号で答えなさい。二つの反復はそれぞれ指定した両端を含む。`<=`は以下を表し，countを増やすのは06行が実行されたときである。

```text
01 data = [2, 1, 3]
02 count = 0
03 iを0から2まで1ずつ増やしながら繰り返す:
04     jを0からiまで1ずつ増やしながら繰り返す:
05         if data[j] <= data[i]:
06             count = count + 1
07 表示する(count)
```

ア　5

イ　2

ウ　3

エ　6

正答：ア

解説：

- ア：iが0のとき1回，1のとき1回，2のとき3回，06行が実行される。合計5が表示される。jはiと同じ値まで取り，その場合も条件を満たす。
- イ：比較を`<`へ変更し等しい場合を除くと2になる。しかし，提示されたコードは`<=`なので，jとiが同じ場合も数える。
- ウ：jとiが同じ3組は全て条件を満たす。さらに，iが2のときのjが0・1の2組も条件を満たすため，3ではない。
- エ：05行の比較自体は合計6回行われるが，iが1・jが0では2が1以下という条件を満たさない。その1回ではcountを増やさないため，表示は5になる。

## 模試35・問19

次のプログラムを実行したときに表示される値として正しいものを，下のア～エの中から一つ選んで記号で答えなさい。nは正の整数とし，`a % b`はaをbで割った余り，`a // b`は整数の商を表す。0を2で割った余りも0である。

```text
01 n = 40308
02 total = 0
03 n > 0の間，繰り返す:
04     digit = n % 10
05     if digit % 2 == 0:
06         total = total + digit
07     n = n // 10
08 表示する(total)
```

ア　4

イ　12

ウ　15

エ　8

正答：イ

解説：

- ア：偶数の桁の個数は，8・0・0・4の4個である。しかし，06行は個数を1ずつ増やす処理ではなく，その桁の値を加える処理である。
- イ：digitは8，0，3，0，4の順になる。偶数の桁8・0・0・4を加え，totalは8，8，8，8，12と変化するので，12を表示する。
- ウ：全ての桁の和は15だが，3は05行の条件を満たさない。3を加えず，偶数の桁の和12を表示する。
- エ：最初に取り出した桁8だけの値である。反復はnが0になるまで続き，途中の0や3を経て4も処理されるため，最後のtotalは12となる。
