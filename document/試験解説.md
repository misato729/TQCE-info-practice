# 高等学校（情報）教員資格認定試験 科目Ⅰの出題範囲

## 受験案内に記載されている出題範囲

令和8年度の受験案内では、科目Ⅰの出題範囲は、教職専門科目に関する内容と高等学校「情報」に関する事項で構成されています。

教職専門科目については、教育職員免許法施行規則第5条第1項表における、次の科目に関する専門的事項が対象です。

* 教育の基礎的理解に関する科目
* 道徳、総合的な学習の時間等の指導法及び生徒指導、教育相談等に関する科目

試験は全20問の択一式で、問1から問15までは主に教職専門科目、問16から問20までは主に高等学校「情報」に関する事項が出題されています。

## 過去問から見た実際の出題傾向

受験案内の表現は広いため、具体的に何を勉強すればよいか分かりにくい部分があります。令和6年度から令和8年度までの過去問を分析すると、実際の出題分野はおおむね次のように整理できます。

| 問題番号 | 主な出題分野 | 主な出題元・内容 |
| --- | --- | --- |
| 問1〜問2 | 1.1 教育基礎総論 | 日本教育史、西洋教育史、教育の理念・思想など |
| 問3〜問5 | 1.3 教育制度総論 | 教育基本法、学校教育法、地方公務員法、教育公務員特例法など |
| 問6 | 1.6 教育課程編成論 | 教育課程の編成・実施、学習評価、カリキュラム・マネジメントなど |
| 問7 | 内容に応じて分類 | 1.5 特別支援教育、1.6 教育課程編成論、2.5・2.7 生徒指導・進路指導論など |
| 問8 | 2.1 総合的な学習・探究論 | 総合的な探究の時間、学習指導要領解説など |
| 問9 | 2.0 道徳教育論 | 高等学校における道徳教育など |
| 問10 | 2.2 特別活動論 | 特別活動、学習指導要領解説など |
| 問11 | 2.5 生徒指導・進路指導論 | 生徒指導提要、生徒指導の基本的な考え方など |
| 問12 | 1.5 特別支援教育 | 発達障害に限定しない、特別支援教育における障害全般 |
| 問13〜問14 | 1.4 教育心理学 | 青年期の発達、発達理論、学習理論など |
| 問15 | 1.3 教育制度総論 | 「令和の日本型学校教育」答申、個別最適な学び、協働的な学びなど |
| 問16〜問18 | 内容に応じて分類 | 3.1 情報科専門科目、3.2 情報科教育法。高等学校学習指導要領及び解説「情報編」など |
| 問19〜問20 | 3.1 情報科専門科目 | アルゴリズム、プログラム、データサイエンス、統計など |

## 本サイトの小分類

大分類は「教職教養」「情報科特有」のままとし、小分類には教育職員免許法施行規則上の区分を踏まえ、大学の教職課程で対応する科目名を使用します。

### 教職教養

* 1.1 教育基礎総論
* 1.2 教職概論
* 1.3 教育制度総論
* 1.4 教育心理学
* 1.5 特別支援教育
* 1.6 教育課程編成論
* 2.0 道徳教育論
* 2.1 総合的な学習・探究論
* 2.2 特別活動論
* 2.3 教育方法・技術論
* 2.4 教育におけるICT活用
* 2.5 生徒指導・進路指導論
* 2.6 生徒理解と教育相談
* 2.7 生徒指導・進路指導論

### 情報科特有

* 3.1 情報科専門科目
* 3.2 情報科教育法

問7及び問16〜問18は、年度や問題内容によって該当する科目が変わるため、問番号だけで小分類を固定しません。

## 予想問題の作成方針

予想問題は令和8年度の難易度と選択肢の情報量を基準とします。「適切なもの」を選ぶ問題を中心としつつ、「適切でないもの」を選ぶ問題も一部に含めます。解説では、正答の根拠だけでなく、各誤答選択肢が誤りである理由も示します。

法令、学習指導要領、答申などの抜粋穴埋め問題は、公式原典の該当箇所を確認し、過去問と同様の導入文で作成します。出典は資料名と章節を明記し、原典へのリンクを付けます。

## 注意事項

高等学校（情報）教員資格認定試験は令和6年度に始まった試験であり、確認できる過去問はまだ多くありません。今後、問題の構成や出題分野が変わる可能性があります。

この分類は出題範囲を限定するものではなく、過去問の傾向をもとに学習しやすく整理した本サイト独自の分類です。受験にあたっては、最新の受験案内、学習指導要領、関係法令なども確認してください。
