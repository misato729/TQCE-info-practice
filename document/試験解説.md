# 高等学校（情報）教員資格認定試験 科目Ⅰの出題範囲

## 受験案内に記載されている出題範囲

令和8年度の受験案内では、科目Ⅰの出題範囲は、教職専門科目に関する内容と高等学校「情報」に関する事項で構成されています。

教職専門科目については、教育職員免許法施行規則第5条第1項表における、次の科目に関する専門的事項が対象です。

* 教育の基礎的理解に関する科目
* 道徳、総合的な学習の時間等の指導法及び生徒指導、教育相談等に関する科目

試験は全20問の択一式で、問1から問15までは主に教職専門科目、問16から問20までは主に高等学校「情報」に関する事項が出題されています。

## 過去問から見た実際の出題傾向

受験案内の表現は広いため、具体的に何を勉強すればよいか分かりにくい部分があります。令和6年度から令和8年度までの過去問を分析すると、実際の出題分野はおおむね次のように整理できます。

| 問題番号 | 主な出題分野 | 主な出題元・内容 |
| --- | --- | --- |
| 問1〜問2 | 教育史 | 日本教育史、西洋教育史、教育原理、学習理論など |
| 問3〜問5 | 教育法規 | 教育基本法、学校教育法、地方公務員法、教育公務員特例法など |
| 問6〜問10 | 学習指導要領 | 教育課程と学習評価、生徒の発達の支援、総合的な探究の時間、道徳教育、特別活動など |
| 問11 | 生徒指導 | 生徒指導提要、生徒指導の基本的な考え方など |
| 問12〜問14 | 教育心理 | 発達障害、青年期の発達、学習理論など |
| 問15 | 令和の日本型学校教育 | 個別最適な学び、協働的な学び、中央教育審議会答申など |
| 問16〜問18 | 学習指導要領（情報） | 高等学校学習指導要領及び学習指導要領解説「情報編」など |
| 問19 | アルゴリズム | 基本情報技術者試験相当のアルゴリズムなど |
| 問20 | データサイエンス | データの分析、統計、データサイエンスに関する内容など |

本サイトでは、問題を探しやすくするため、法令上の科目区分をそのまま使用せず、過去問の出題傾向に合わせて次の9分野に分類します。

1. 教育史
2. 教育法規
3. 学習指導要領
4. 生徒指導
5. 教育心理
6. 令和の日本型学校教育
7. 学習指導要領（情報）
8. アルゴリズム
9. データサイエンス

## 注意事項

高等学校（情報）教員資格認定試験は令和6年度に始まった試験であり、確認できる過去問はまだ多くありません。今後、問題の構成や出題分野が変わる可能性があります。

この分類は出題範囲を限定するものではなく、過去問の傾向をもとに学習しやすく整理した本サイト独自の分類です。受験にあたっては、最新の受験案内、学習指導要領、関係法令なども確認してください。
