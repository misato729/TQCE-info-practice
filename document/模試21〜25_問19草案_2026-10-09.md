## 模試21・問19

次のプログラムは，配列 a の各要素を一つ右の位置へ移し，元の末尾の要素を先頭へ移すものである。空欄 ①・② に当てはまるものの組合せとして正しいものを，下のア～エの中から一つ選んで記号で答えなさい。

配列の添字は0から始まる。`=` は代入を表し，行頭の字下げは処理の範囲を表す。`range(a, b)` は a から b−1 までを1ずつ増やして取り出す。`range(a, b, -1)` は a から b より大きい整数を1ずつ減らして取り出す。`print(a)` は配列の要素を先頭から順に表示する。

```text
01 a = [3, 8, 2, 7, 5]
02 last = a[4]
03 for i in 【①】:
04     a[i] = a[i - 1]
05 a[0] = 【②】
06 print(a)
```

| 選択肢 | ① | ② |
| --- | --- | --- |
| ア | range(4, 0, -1) | last |
| イ | range(4, 0, -1) | a[4] |
| ウ | range(1, 5) | last |
| エ | range(1, 5) | a[4] |

正答：ア。

解説：末尾の値5を last に退避し，後ろから順に要素を移す。前から移すと，まだ読み取る必要のある値を上書きしてしまう。

| 処理 | 配列 a |
| --- | --- |
| i = 4 | [3, 8, 2, 7, 7] |
| i = 3 | [3, 8, 2, 2, 7] |
| i = 2 | [3, 8, 8, 2, 7] |
| i = 1 | [3, 3, 8, 2, 7] |
| a[0] = last | [5, 3, 8, 2, 7] |

- ア：正しい。元の全要素を保持しながら，一つ右へ移せる。
- イ：05行の時点で a[4] は7に変わっているため，結果は [7, 3, 8, 2, 7] となる。退避した last を使う必要がある。
- ウ：前から移すため，元の先頭の値3で後続の要素が順に上書きされ，結果は [5, 3, 3, 3, 3] となる。
- エ：前からの上書きと，変更後の a[4] の参照が重なり，結果は [3, 3, 3, 3, 3] となる。

参考出典：[文部科学省『高等学校情報科「情報Ⅰ」教員研修用教材（本編）』第3章・学習14（1）リスト（122頁／PDF28頁）](https://www.mext.go.jp/content/20200722-mxt_jogai02-100013300_005.pdf#page=28)

## 模試22・問19

次のプログラムは，二次元配列 M の各行の要素の合計を，先頭の行から順に一つずつ表示するために作成したものである。しかし，このままでは意図した表示にならない。修正方法として正しいものを，下のア～エの中から一つ選んで記号で答えなさい。

添字は0から始まり，`M[i][j]` は i 行目の j 列目の要素を表す。`range(0, 3)` は0，1，2を順に取り出す。`=` は代入を表し，行頭の字下げは処理の範囲を表す。`print(s)` は s の値を表示する。

```text
01 M = [[2, 5, 1], [4, 3, 2], [6, 1, 4]]
02 s = 0
03 for i in range(0, 3):
04     for j in range(0, 3):
05         s = s + M[i][j]
06     print(s)
```

ア　02行はそのままとし，06行を一段深く字下げして，内側の繰返しの中で05行の直後に実行する。

イ　02行を削除し，`s = 0` を04行の直前に挿入する。この処理は外側の繰返しの中，内側の繰返しの外で実行する。

ウ　02行を削除し，`s = 0` を05行の直前に挿入する。この処理は内側の繰返しの中で実行する。

エ　02行はそのままとし，06行の字下げをなくして，外側の繰返しが終了した後に実行する。

正答：イ。

解説：一つの行の合計を求め始めるたびに s を0へ戻し，その行の全要素を加算した後に表示する必要がある。

| 行の添字 i | その行の加算中の s | 表示する値 |
| --- | --- | --- |
| 0 | 2 → 7 → 8 | 8 |
| 1 | 4 → 7 → 9 | 9 |
| 2 | 6 → 7 → 11 | 11 |

- ア：初期化は一度だけで，加算するたびに表示するため，2，7，8，12，15，17，23，24，28の9個が表示される。
- イ：正しい。行が変わるたびに初期化され，8，9，11が表示される。
- ウ：要素を加算するたびに0へ戻るため，各行の最後の要素である1，2，4が表示される。
- エ：全行を通した合計を一度だけ表示するため，28だけが表示される。

参考出典：[文部科学省『高等学校情報科「情報Ⅰ」教員研修用教材（本編）』第3章・学習13「反復の例」（117頁／PDF23頁）](https://www.mext.go.jp/content/20200722-mxt_jogai02-100013300_005.pdf#page=23)，[学習14（1）リスト（122頁／PDF28頁）](https://www.mext.go.jp/content/20200722-mxt_jogai02-100013300_005.pdf#page=28)

## 模試23・問19

次のプログラムは，文字列 text の中に文字の並び「ABA」が現れる回数を数えるものである。文字の位置が重なっている場合も別々に数える。空欄 ①・② に当てはまるものの組合せとして正しいものを，下のア～エの中から一つ選んで記号で答えなさい。

文字の位置は0から始まり，`text[i]` は i 番目の文字，`len(text)` は文字数を表す。`=` は代入，`==` は等しいかの比較，`and` はつないだ条件が全て成り立つことを表す。行頭の字下げは処理の範囲を表し，`while` は条件が成り立つ間，処理を繰り返す。

```text
01 text = "ABABABA"
02 n = len(text)
03 i = 0
04 count = 0
05 while i <= n - 3:
06     if text[i] == "A" and text[i + 1] == "B" and text[i + 2] == "A":
07         count = count + 1
08         i = 【①】
09     else:
10         i = 【②】
11 print(count)
```

| 選択肢 | ① | ② |
| --- | --- | --- |
| ア | i + 3 | i + 1 |
| イ | i + 1 | i + 3 |
| ウ | i + 1 | i + 1 |
| エ | i + 3 | i + 3 |

正答：ウ。

解説：「ABA」の長さは3文字だが，見つけた後も開始位置を1だけ進める必要がある。一致しなかった場合も1だけ進め，全ての開始位置を調べる。

| 開始位置 i | 調べる3文字 | 加算後の count |
| --- | --- | --- |
| 0 | ABA | 1 |

- ア：開始位置0で一致した後，3へ進むため，位置2の一致を見落とす。位置0と4だけが数えられ，表示は2となる。
- イ：位置1で一致しなかった後，4へ進むため，位置2を調べない。位置0と4だけが数えられ，表示は2となる。
- ウ：正しい。位置0，2，4の3か所を数えられる。
- エ：位置0の後は3，6と進む。位置6では05行の条件が成り立たず終了するため，表示は1となる。

## 模試24・問19

次のプログラムは，所持金を15とし，配列 price に入っている価格を先頭から順に調べ，その時点の残額以下の価格の商品を一つずつ購入するものである。購入できない商品は飛ばして次の商品を調べる。商品の順番は変えず，一度購入した商品を取り消すこともない。空欄 ①・② に当てはまるものの組合せとして正しいものを，下のア～エの中から一つ選んで記号で答えなさい。

添字は0から始まり，`range(0, 5)` は0から4までを順に取り出す。`=` は代入を表し，行頭の字下げは処理の範囲を表す。`print(count, remain)` は購入した個数，残額の順に表示する。

```text
01 price = [8, 7, 5, 1, 4]
02 remain = 15
03 count = 0
04 for i in range(0, 5):
05     if price[i] 【①】 remain:
06         remain = 【②】
07         count = count + 1
08 print(count, remain)
```

| 選択肢 | ① | ② |
| --- | --- | --- |
| ア | <= | remain - price[i] |
| イ | < | remain - price[i] |
| ウ | <= | 15 - price[i] |
| エ | < | 15 - price[i] |

正答：ア。

解説：残額と価格が等しい場合も購入できるため，条件は `<=` である。購入後は初期所持金ではなく，その時点の残額から価格を差し引く。

| 商品の価格 | 判定前の残額 | 購入するか | 判定後の残額 | 購入個数 |
| --- | --- | --- | --- | --- |
| 8 | 15 | 購入する | 7 | 1 |
| 7 | 7 | 購入する | 0 | 2 |
| 5 | 0 | 購入しない | 0 | 2 |
| 1 | 0 | 購入しない | 0 | 2 |
| 4 | 0 | 購入しない | 0 | 2 |

- ア：正しい。表示は `2 0` となる。
- イ：価格7が残額7と等しいときに購入しない。その後，価格5と1を購入するため，表示は `3 1` となる。
- ウ：毎回15から価格を引くため，それまでの購入金額が残額へ反映されない。全ての商品を購入した扱いとなり，表示は `5 11` となる。
- エ：価格7は等号を含まない条件のため購入しない。それ以外の4商品を購入した扱いとなり，表示は `4 11` となる。残額の更新方法も誤っている。

## 模試25・問19

次のプログラムを実行したとき，09行で表示される値として正しいものを，下のア～エの中から一つ選んで記号で答えなさい。

`def f(x)` は関数 f の定義であり，`f(y)` を実行すると，その時点の y の値を引数 x として02行から処理を行う。関数内の x と s は呼び出しごとに独立して扱い，`return s` は s の値を呼び出した側へ返す。`range(0, 3)` は0，1，2，`range(0, 2)` は0，1を順に取り出す。`=` は代入を表し，行頭の字下げは処理の範囲を表す。

```text
01 def f(x):
02     s = 1
03     for i in range(0, 3):
04         s = s + x
05     return s
06 y = 2
07 for k in range(0, 2):
08     y = f(y)
09 print(y)
```

ア　7

イ　18

ウ　28

エ　22

正答：エ。

解説：関数 f は呼び出すたびに s を1へ初期化し，引数 x を3回加えるため，戻り値は `3 * x + 1` となる。1回目の戻り値7が y に代入され，2回目は7を引数として処理する。

| 呼び出し | 引数 x | s の変化 | 戻り値・代入後の y |
| --- | --- | --- | --- |
| 1回目 | 2 | 1 → 3 → 5 → 7 | 7 |
| 2回目 | 7 | 1 → 8 → 15 → 22 | 22 |

- ア：7は1回目の呼び出し後の値である。外側の繰返しは2回実行される。
- イ：18は，仮に02行を `s = 0` とした場合の結果である。この変更では y が2 → 6 → 18と変わるが，実際には毎回1から加算する。
- ウ：28は，仮に s を最初に一度だけ1へ初期化し，関数の呼び出しをまたいで値を持ち越した場合の結果である。その変更では2回目を7から始めて7を3回加えることになるが，実際には02行が再び実行される。
- エ：正しい。2回目の戻り値22が最終的な y である。

参考出典：[文部科学省『高等学校情報科「情報Ⅰ」教員研修用教材（本編）』第3章・学習14（3）関数（123～124頁／PDF29～30頁）](https://www.mext.go.jp/content/20200722-mxt_jogai02-100013300_005.pdf#page=29)
