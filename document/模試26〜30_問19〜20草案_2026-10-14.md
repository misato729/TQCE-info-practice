### 問19

次のプログラムは，配列 data の各値を先頭から順に調べ，元の値が偶数ならば2で割った値に，奇数ならば3倍して1を加えた値に置き換え，その結果を配列 out に保存するものである。各値への置換は一度だけ行う。空欄 ①・② に当てはまるものの組合せとして正しいものを，下のア～エの中から一つ選んで記号で答えなさい。

`=` は代入，`==` は等しいかの比較，`!=` は等しくないかの比較，`%` は整数除算の余り，`//` は整数除算の商を表す。`for x in data` は各要素の値を先頭から順に x へ代入して繰り返す。x の変更によって data の要素は変更されない。`if` はその条件を判定し，`elif` は直前の `if` の条件が成立しなかったときだけ次の条件を判定する。行頭の字下げは処理の範囲を表し，`out.append(x)` は out の末尾に x を追加する。

```text
01 data = [2, 3, 4, 5, 6]
02 out = []
03 for x in data:
04     if x % 2 【①】 0:
05         x = x // 2
06     【②】 x % 2 == 1:
07         x = 3 * x + 1
08     out.append(x)
09 print(out)
```

| 選択肢 | ① | ② |
| --- | --- | --- |
| ア | == | if |
| イ | != | elif |
| ウ | != | if |
| エ | == | elif |

正答：エ。

解説：04行で元の値の偶数・奇数を区別する。偶数を2で割った後の値が奇数になる場合もあるので，06行を独立した `if` にすると，同じ値に二つの置換を行ってしまう。

| 元の値 | 適用する処理 | out に追加する値 |
| --- | --- | --- |
| 2 | 2で割る | 1 |
| 3 | 3倍して1を加える | 10 |
| 4 | 2で割る | 2 |
| 5 | 3倍して1を加える | 16 |
| 6 | 2で割る | 3 |

- ア：偶数への最初の処理は正しいが，変換後の値で06行の条件を改めて判定する。2は1を経て4，6は3を経て10になり，表示は `[4, 10, 2, 16, 10]` となる。
- イ：04行が奇数のときに成立するため，奇数を2で割ってしまう。06行は最初の条件が成立しなかった偶数について判定するので，3倍して1を加える処理は実行されず，表示は `[2, 1, 4, 2, 6]` となる。
- ウ：奇数を2で割った後，その結果について06行を判定する。3は1を経て4，5は2となり，偶数はそのままなので，表示は `[2, 4, 4, 2, 6]` となる。
- エ：正しい。元の値に応じて二つの処理のいずれか一方を実行し，表示は `[1, 10, 2, 16, 3]` となる。

### 問20

次の表は，同じ年における二つの市A・Bの人口と交通事故の発生件数を示したものである。人口規模の違いを考慮して比較するため，各市について人口1,000人当たりの発生件数を求める。この指標の値の組合せとして正しいものを，下のア～エの中から一つ選んで記号で答えなさい。

| 市 | 人口（人） | 交通事故の発生件数（件） |
| --- | ---: | ---: |
| A | 18,000 | 36 |
| B | 60,000 | 90 |

| 選択肢 | Aの人口1,000人当たりの件数 | Bの人口1,000人当たりの件数 |
| --- | ---: | ---: |
| ア | 2.0 | 1.5 |
| イ | 2.0 | 0.15 |
| ウ | 0.2 | 1.5 |
| エ | 0.2 | 0.15 |

正答：ア。

解説：人口1,000人当たりの件数は「発生件数÷人口×1,000」で求める。総件数と，人口当たりの件数を区別する。

```text
A：36÷18,000×1,000＝2.0（件）
B：90÷60,000×1,000＝1.5（件）
総件数：Bの方が多い（90＞36）
人口1,000人当たり：Aの方が多い（2.0＞1.5）
```

- ア：正しい。総件数ではBの方が多いが，人口1,000人当たりの件数ではAの方が多い。
- イ：Aの値は正しいが，Bの0.15は人口100人当たりの件数であり，指定された1,000人当たりの値ではない。
- ウ：Bの値は正しいが，Aの0.2は人口100人当たりの件数であり，指定された1,000人当たりの値ではない。
- エ：両市とも人口100人当たりの値となっており，指定された人口1,000人当たりの値の10分の1になっている。

### 問19

次のプログラムは，二つの変数 x，y を3回更新するものである。各回の更新では，更新前の x と y の和を新しい x とし，更新前の x を新しい y とする。空欄 ①・② に当てはまるものの組合せとして正しいものを，下のア～エの中から一つ選んで記号で答えなさい。

`=` は右辺の値を求めた後，その値を左辺へ代入することを表す。各行は上から順に実行される。`range(0, 3)` は0，1，2を順に取り出し，行頭の字下げは処理の範囲を表す。t は更新前の値を一時的に保存するための変数である。

```text
01 x = 2
02 y = 3
03 for i in range(0, 3):
04     t = 【①】
05     x = x + y
06     y = 【②】
07 print(x)
```

| 選択肢 | ① | ② |
| --- | --- | --- |
| ア | x | x |
| イ | x | t |
| ウ | y | t |
| エ | y | x |

正答：イ。

解説：05行で x を更新すると，更新前の x は x から読み取れなくなる。その値を04行で t に保存し，06行で y へ代入する必要がある。

| 更新回数 | 更新前の x，y | t | 更新後の x，y |
| --- | --- | --- | --- |
| 1回目 | 2，3 | 2 | 5，2 |
| 2回目 | 5，2 | 5 | 7，5 |
| 3回目 | 7，5 | 7 | 12，7 |

- ア：更新前の x を退避する点は正しいが，06行で更新後の x を y に入れてしまう。x，y はともに5，10，20と変わり，表示は20となる。
- イ：正しい。各回の古い x を次の y に引き継ぐため，表示は12となる。
- ウ：退避するのが更新前の y なので，y は3のまま変わらない。x は5，8，11と変わり，表示は11となる。
- エ：退避する値が y であり，さらに y へ更新後の x を代入する。t は更新に使われず，アと同様に表示は20となる。

### 問20

図書館の利用状況を調べるため，次の二つの資料を作成した。資料の構造と分析に関する記述として適切なものを，下のア～エの中から一つ選んで記号で答えなさい。

資料Ⅰ：ある一つの図書館について，2024年1月から2025年12月までの各月の来館者数を記録した。1行が一つの月に対応し，年月と来館者数の列を持つ。

資料Ⅱ：40の図書館について，2025年12月の来館者数と延床面積を記録した。1行が一つの図書館に対応し，図書館名，来館者数及び延床面積の列を持つ。

ア　資料Ⅰは時系列データ，資料Ⅱはクロスセクションデータである。資料Ⅰの来館者数を小さい順に並べたときの隣り合う値の差から，前月と比べた増減を分析できる。

イ　資料Ⅰは24個の月を対象とするクロスセクションデータ，資料Ⅱは40の図書館を対象とする時系列データである。記録の件数と対象の数に基づき，両者を分類できる。

ウ　資料Ⅰは一つの図書館を時間に沿って記録した時系列データ，資料Ⅱは同じ月の複数の図書館を記録したクロスセクションデータである。前者は時間的な推移，後者は図書館間の違いを調べるために利用できる。

エ　資料Ⅰは時系列データ，資料Ⅱはクロスセクションデータである。資料Ⅱで延床面積の大きい図書館ほど来館者数が多ければ，同じ図書館が年月とともに面積を広げたときの来館者数の変化も記録されていると解釈できる。

正答：ウ。

解説：データが「同じ対象について異なる時点を記録しているか」「同じ時点について異なる対象を記録しているか」を区別する。

- イ：両者の分類が逆である。24件，40件という件数自体では分類できず，各行がどの対象・時点に対応するかを確認する。
- ウ：正しい。資料Ⅰは同じ図書館を24か月にわたって観測し，資料Ⅱは同じ月に40の図書館を観測している。
- エ：資料の分類は正しいが，異なる図書館間の違いを，同じ図書館の時間的変化と取り違えている。資料Ⅱには，各図書館が面積を広げる前後の来館者数は記録されていない。

### 問19

次のプログラムは，配列 data の5個の値の平均値について，小数点以下を切り捨てた整数を表示するために作成したものである。しかし，このままでは意図した表示にならない。修正方法として正しいものを，下のア～エの中から一つ選んで記号で答えなさい。

`=` は代入を表し，非負の整数について `a // b` は a を b で割った商の小数点以下を切り捨てた値を表す。`for x in data` は各要素の値を先頭から順に x へ代入して繰り返す。行頭の字下げは処理の範囲を表す。

```text
01 data = [3, 8, 4, 6, 9]
02 total = 0
03 for x in data:
04     total = total + x
05     total = total // 5
06 print(total)
```

ア　05行の位置はそのままとし，06行を字下げして，繰返しの中で05行の直後に実行する。

イ　05行を03行の直前へ移し，字下げをなくして，繰返しが始まる前に実行する。

ウ　05行の字下げをなくし，繰返しが終了してから06行の直前に実行する。

エ　05行を04行の直前へ移し，字下げはそのままとして，繰返しの中で加算の前に実行する。

正答：ウ。

解説：全ての値の合計30を求めた後，一度だけ5で割ると，平均値の整数部分6が得られる。加算の途中で除算すると，それまでの合計自体が変更され，切捨ても繰り返される。

```text
加算後の total：3 → 11 → 15 → 21 → 30
繰返し終了後：30 // 5 = 6
```

- ア：加算と整数除算を繰り返す点は変わらず，途中の値0，1，1，1，2を順に表示する。平均値の整数部分を一つ表示する処理にはならない。
- イ：初期値0を5で割った後，全要素を加算するため，表示は合計の30となる。
- ウ：正しい。除算を全要素の加算後に一度だけ行い，6を表示する。
- エ：直前の total を5で割ってから次の値を加えるため，total は3，8，5，7，10と変わり，表示は10となる。

### 問20

4人の通学時間を，次の区分に従って符号1～3へ変換した。元の通学時間と，変換後のデータの性質に関する記述として適切なものを，下のア～エの中から一つ選んで記号で答えなさい。

| 区分 | 通学時間 | 記録する符号 |
| --- | --- | ---: |
| 短い | 0分以上30分未満 | 1 |
| 中程度 | 30分以上60分未満 | 2 |
| 長い | 60分以上 | 3 |

| 生徒 | A | B | C | D |
| --- | ---: | ---: | ---: | ---: |
| 元の通学時間（分） | 20 | 30 | 55 | 90 |
| 変換後の符号 | 1 | 2 | 2 | 3 |

ア　変換後の符号は順序尺度である。符号2となったBとCについて，どちらの通学時間が長いか，何分違うかを，符号だけから判断することはできない。

イ　変換後の符号は順序尺度である。符号の平均値2を中程度の区分の中央45分に対応させれば，元の4人の平均通学時間が得られる。

ウ　符号には1，2，3の順序があり，隣り合う符号の差は1であるため，変換後のデータは間隔尺度である。符号の差が等しければ，元の通学時間の差も等しい。

エ　変換後の符号は順序尺度である。符号2の生徒の人数が符号1の生徒の2倍であるため，それぞれの区分に属する生徒の通学時間の合計も同じ2倍の関係になる。
