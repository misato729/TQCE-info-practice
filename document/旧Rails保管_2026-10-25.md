# 旧Railsコードのローカル保管と現行ツリーからの除外

対象は削除前コミット `da0366aa27b3f80f07544c57d9ede2786481b8e5` の `backend/`。旧Railsのアプリ、Gemfile、Dockerfile、Fly設定、マイグレーション、テスト・承認資料を現行Gitツリーから外す。旧DBと既存バックアップ、現在のNuxt/Nitroの機能は維持する。Git履歴の書換えやNetlifyへのデプロイは行わない。

## ローカル保管

- 作業フォルダ: `operations/private/legacy-rails-20261025/backend/`
- 追跡対象のアーカイブ: `operations/private/legacy-rails-20261025/tracked-backend-da0366a.tar.gz`
- 非公開の照合記録: 同じディレクトリの `preservation-report.json`
- アーカイブのSHA-256: `7c629a96dec39818aada284cd32283f315c2da5f3ad3f0d3d10944a8246e650c`

追跡対象268ファイルについて、Gitアーカイブと作業ファイルのSHA-256を全件照合した。旧フォルダ全体は同一ディスク内で移動し、ログ・一時ファイル・ローカル専用設定も含めて保持した。追跡対象は移動後の内容・inode・更新時刻・権限も照合し、一致を確認した。保管ディレクトリは0700、アーカイブと照合記録は0600で、GitとDockerのビルド対象から除外する。

既存の非公開作業ファイル248件は、移動前後のサイズ・更新時刻・inode・権限が一致した。旧DBの `tqce-info-practice_postgres_data`、現行DBの `tqce-info-practice_nuxt_postgres_data`、旧依存ボリュームは削除・再作成しない。既存の暗号化バックアップや `legacy-rails-20261024/` のアーカイブも保持する。

## 現行の検査資料

現行の表示検査スクリプトが直接参照していた承認JSON1件を、内容を変更せず [表示検査用fixture](question-review-fixtures/README.md) に移設した。原本とのSHA-256一致を確認し、表示検査の参照先だけを変更した。その他の旧検査・原典資料は旧Rails一式とともにローカルへ保管する。

Prismaの適用済みマイグレーション、既存DBの `fk_rails_*` 制約名、アーカイブ取込みの互換性は現行機能として保持する。Railsアプリの削除を理由にDBスキーマや問題データを変更しない。旧DBの必要時だけ使う `docker-compose.legacy.yml` も維持する。

## 過去資料の参照

日付付き作問・検証資料に記載された `backend/` は、ローカル保管先または削除前コミットのパスを指す。過去の検査結果を書き換えず、必要なファイルを履歴から読み取る。

```sh
git show da0366a:backend/test/fixtures/approved_question_catalog/README.md
```

保管フォルダには秘密値や実データを含むローカル専用ファイルがあるため、Gitへの再追加・公開・本番イメージへの同梱をしない。旧コードを使う検査や復旧は対象を明示した隔離環境で行い、通常の開発・本番運用へ戻さない。
